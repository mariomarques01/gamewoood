# Prototype 0.1

## Controls
Configure Godot Input Map actions:
- move_left: A / Left arrow
- move_right: D / Right arrow
- move_forward: W / Up arrow
- move_back: S / Down arrow

## Run
Open project.godot in Godot 4, set up Input Map, then press F5.

## Status
This is a movement-only graybox, not yet a playable shooter. Touch controls, combat, alien AI and export templates are future milestones.
