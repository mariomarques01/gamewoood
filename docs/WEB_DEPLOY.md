# Godot web preview

The GitHub Actions workflow exports Godot 4.3 Web and deploys it to GitHub Pages after pushes to main.

One-time repository configuration: Settings > Pages > Build and deployment > Source: GitHub Actions.

Expected URL after a successful deploy: https://mariomarques01.github.io/gamewoood/

The web preview is not an Android or iOS app. Check the Actions tab if the export or deployment fails.
